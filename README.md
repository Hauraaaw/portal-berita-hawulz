# Hawulz

Website portal berita berbasis Laravel 12 dan Filament v5.

login admin : admin@hawulz.com
password: 123

## Features
- Login Admin
- Dashboard Admin
- CRUD Author
- CRUD News Category
- CRUD News
- CRUD Banner
- Featured News
- Upload Thumbnail

## Tech Stack
- Laravel 12
- Filament v5
- Tailwind CSS
- MySQL

## Installation

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan storage:link
php artisan serve
```
